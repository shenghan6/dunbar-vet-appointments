# Procurement Proposal for Dunbar Vet Appointment System
Student Name: ZiangDong

## 1. Project Background
Dunbar Veterinary Clinic plans to implement a web-based appointment management system. The system will help clinic staff manage booking schedules, store pet and owner information, and allow clients to submit appointment requests online. This procurement proposal describes the requirements, estimated cost, timeline and acceptance criteria for purchasing this software system.

## 2. Business Objectives
- Reduce manual paperwork and administrative workload for reception staff.
- Enable pet owners to view available time slots and book appointments online.
- Maintain secure records for pets, owners and consultation history.
- Provide clinic administrators with functions to view, modify and cancel bookings.

## 3. Functional Requirements
3.1 User registration and secure login for clinic staff and customers
3.2 Calendar view to display available vet time slots
3.3 Create, modify and cancel appointment bookings
3.4 Store and manage pet profile and owner contact details
3.5 Admin dashboard for staff to manage all appointments

## 4. Non-functional Requirements
4.1 Usability: Simple user interface for staff without advanced technical skills.
4.2 Security: Protect personal client data and comply with privacy requirements.
4.3 Reliability: The system should remain available during clinic opening hours.
4.4 Performance: Pages should load quickly under normal user access volume.

## 5. Hardware and Software Procurement
### 5.1 Web Hosting Service
Cloud hosting to run the web application, with regular backup support.
### 5.2 Workstation Devices
Existing clinic desktop computers can be used; no new PCs required.
### 5.3 Software
Web application licence, database service, security updates and maintenance.
